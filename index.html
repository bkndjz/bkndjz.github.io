Stardew Valley

这段时间一直在折腾如何让qqagent接入游戏，我的第一个目标是星露谷物语，并且目前已经有明显的成效，已经可以实现基本的游玩。
总体上的思路是本地写好批量脚本，包括清理，种植，挖矿，钓鱼（这个是打了mod，因为难以实现长按远抛）等，再由云端下达指令调用脚本，依次达成减少token消耗的目的。
下面是在这过程中遇上的一些问题和最终解决方案：
环境：代理变量大小写重复搞崩 MSBuild → 绕开项目系统，直接 csc + build.rsp。Harmony PatchAll 静默不 hook → 手动 Patch。

API 静默失效（最坑，不报错≠生效）：pressUseToolButton 空挥（游戏不认合成输入）；Tool.DoFunction 对杂草/锄地/浇水无反应 → 绕开 UI 直接改世界状态（删 object / 铺 HoeDirt / 置 state=1）。

存档：SaveGame.Save() 返回 ok 但不写盘 → 只有过夜能落盘。

就绪判断：断多人后 IsWorldReady 变 false，动作全回”没进游戏” → 自建 Ready.World。

前缀匹配："FarmHouse".StartsWith("Farm") → goto 回”已到达”，人不动 → 只认精确同名或 名+数字。

排序在截断之后：凑够 limit 才排序 → 舍近求远 → 先全收、再排、再截。

找错集合：plant 用”只找已有作物”的函数找空地 → 永远 planned 0。

动画被打断：180ms 就放行 + 引擎不等 PauseForSingleAnimation → “挥一半就走”。

词表不同步：hoe/water_all 游戏侧没实现、工具描述里也没写 → 模型自己造词 → E_UNKNOWN_TASK。

参数串位：kind 被填成 private → 白名单 + 扫包兜底 + 报错列出可用值。

进程：重启 poller 重放 199 条历史（含 quit）把游戏关了 → processed-id 持久化；open_sftp 无超时卡死 → 加超时 + 改追加写；pythonw 静默无痕 → 日志重定向。

数据：存档被游戏自己删（Farm_Delete），官方备份只在过夜时触发、我们从不过夜 → 一整天蒸发。补救：读档前自动整份备份。

最后，我认为值得比较重要的是在清杂，挖矿时，最开始用角色周围物品数量判断行动成功与否，但角色行动导致的扫描数量改变会引发误判，因而改成用物品绝对坐标进行判断。

cloud serve

今天费了一番功夫把qqagent转移到了云服务器上，用的是阿里云的学生300代金卷，租了个2核2G的小服务器。
最开始用的是windows系统，因为我电脑用的就是windows系统，比较熟悉，但因为用的Server Core 无图形界，SnowLuma 起不来。
于是便转成liunx系统，有使得本机 ssh 工具全废，只能改用 Python + paramiko，后来又遇上zip 解压失败，Docker 装不上，OneBot 配置不生效等问题，逐一解决后终于完成了云端的部署，现在qqagent可以24h在线了，接下来准备继续完善桌宠和试试用AI控制手机。

3D desktop pet model rendering

在github上看到一个用自然语言驱动3D建模的模型（https://github.com/sola1039/HAST-SEC），突发奇想，想要做一个3D模型的桌宠。
说干就干，我下载了这个模型，并从模之屋上下载了沃雅妮莎的人物模型，在模型导入的过程中，我遇到了几个明显的问题：
1是模型渲染时角色身上的配饰始终呈灰白色，加上材质自发光就解决了；
2是模型腿部总是发生穿模，穿过裙摆，最开始我以为是碰撞箱的问题，结果是因为时间步恒定为 0，弹簧物理从没跑过；
3是两只脚会内八，脚尖穿模，是因为脚移动是搞错了旋转角度；
4运行一段时间后会卡死，其实是因为求解器连续 0.5 秒判定姿态不可行，就会永久放弃并暂停，即模型算不出可行动作后放弃运算，我将其改为重置模型状态，勉强算是解决了；
最后说一下为什么要打上qqagent的标签：这主要和我后期计划有关，我准备之后给模型提前预存一些常见动作后接入qqagent，由qqagent指挥动作，我认为这会是一个很有意思的想法。

My First Post

作为一名网络安全方面的大一新生，这是我的第一篇博客。
为什么会想到要写博客呢？一者是学长的建议，一者是也想要记录一些东西。
至于以后会在博客中写什么？目前的想法是写一些学习中遇到的问题与收获，还有记录一些我做的小项目。
一是用opencode借助godot引擎做了一个卡牌游戏。
从高三毕业时就开始做了，基础的战斗引擎差不多都实现了，接下来准备调整UI，制作特效和音效。题材上选的是全职法师（我小学时蛮喜欢的一本小说，虽然后来番外写烂了，但那时候我已经把主要机制写的差不多了，也想给少年的热爱一个交代，便没有放弃），玩法上较多的参考了炉石传说，加上了进阶系统（修炼加点和突破检测卡了好久）和羁绊系统（更多只是一些剧情彩蛋吧，基本很难凑齐，但效果也是非常NB），我想的是做出多魔法系不同搭配的效果，但具体可能还要看后期调整了。
二是制作我的世界mod。
这个我选取的是修仙题材，可能比不上市面上的那些mod，但我还是希望尽可能的还原我心目中的修仙世界，主要借助的工具是automods网站和dsh。对于这个mod，写设定的时候一不小心写嗨了，设定里写了十多个新生物群系，还有配套的丹器符阵，灵宠，boss，npc，工作量怕是非常的大，目前只是用automods勉强调整好了雷劫系统，自己在blockbench中建模了一个雷龙（雷劫的boss）但花的时间太多了，automods建模又太贵，于是尝试用dsh用MCP接入blockbench建模了一个竹叶青蛇及动画，意外的效果还不错，只有头部需要我手动调整一些，就连贴图都只需要微调就有不错的效果。而且昨天deepseek崩溃还反了60块token，是件值得高兴的事情。
三是养了一个qqagent。
用的是b站上找的框架，接的是ds的api，在网上下了一些插件，又根据实际使用经历，自己用opencode写了一些插件，人设是与群友讨论后，用ds和gpt写提示词做出来的沃雅妮莎。我自己写的插件主要是加强角色扮演类的，例如人生经历知识库，好感度系统之类的，我比较喜欢的是语音生成的插件，调用本地模型生产语音，那时候为了调音色，反复修改了几个小时的提示词和种子。这篇博客也是在qqagent的指导下完成的，当然内容是我自己写的，主要借助她了解了一些工具（hexo），以及如何上传。
这是我的第一篇博客。2026.10.16
