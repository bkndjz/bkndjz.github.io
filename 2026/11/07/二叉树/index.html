数据结构

这几天在恶补数据结构，主要是单链表的操作和二叉树。
对于单链表操作，主要是增，删。对于增，头尾的增很简单，而在中间增，则要注意用两个指针提前储存增添位置前后的结构体，而删则是要用到三个指针。
比较难的是二叉树。
首先是树的建立与遍历，分为前中后序。
前序，先输出当前节点，然后递归进入左节点，输出，再进入左节点，直到左边走到头。
再递归进入右节点输出，右节点也走到头后，再回到进入右节点的那个左节点，再往回走一步，继续找右节点，直到遍历完整棵树。
void head(const t* tree)
{
const t now = tree;
printf(“%c “, now.num);
if (now.l)
head(now.lc);
if (now.r)
head(now.rc);
}
中序，先向左节点走到头，再输出当前节点，再递归进入右节点，然后继续找左节点走到头输出。
右节点走到头则回到进入的左节点，再往回走一步，重复上述步骤.
void mid(const t tree)
{
const t now = tree;
if (now.l)
mid(now.lc);
printf(“%c “, now.num);
if (now.r)
mid(now.rc);
}
后序，先向左走到头，在向右走到头，然后输出节点，然后回到上一个节点，重复.
void last(const t tree)
{
const t now = tree;
if (now.l)
last(now.lc);
if (now.r)
last(now.rc);
printf(“%c “, now.num);
}
然后是二叉树的线索化，首先要加入两个变量用于记录左边和右边分别是子树还是线索
1头节点左端连二叉树的根节点，右边连输出的最后一个节点，节点左边为空则连接它的前驱，右边为空则连接它的后继，按序输出的第一个和最后一个节点，左右节点分别连接头节点.
线索化类似遍历，只不过将输出改为线索连接，并且要用全局变量来记录前驱。需要注意的是递归时要加入是否是子树的判断，否则可能陷入无限递归的死循环。
void h1(t tree)
{
if (tree == NULL) return;
else
{
if (tree->lc == NULL) tree->lc = pre;
if (pre->rc == NULL) pre->rc = tree;
pre = tree;
if (tree->l == 1) h1(tree->lc);
if (tree->r == 1) h1(tree->rc);
}
}
void h(t** head, t* tree)
{
(*head)->l = 1;
(*head)->r = 0;
(*head)->rc = *head;
if (tree == NULL) (*head)->lc = *head;
else
{
pre = *head;
(*head)->lc = tree;
h1(tree);
(*head)->rc = pre;
pre->rc = *head;
}
}

void m1(t* tree)
{
if (tree == NULL) return;
else
{
if (tree->l == 1) m1(tree->lc);
if (tree->lc == NULL) tree->lc = pre;
if (pre->rc == NULL)pre->rc = tree;
pre = tree;
if (tree->r == 1) m1(tree->rc);
}
}
void m(t** head, t* tree)
{
(*head)->l = 1;
(*head)->r = 0;
(*head)->rc = *head;
if(tree==NULL) (*head)->lc = *head;
else
{
(*head)->lc = tree;
pre = *head;
m1(tree);
pre->rc = *head;
(*head)->rc = pre;
}
}

void la1(t* tree)
{
if (tree == NULL) return;
else
{
if (tree->l == 1) la1(tree->lc);
if (tree->r == 1) la1(tree->rc);
if (tree->lc == NULL) tree->lc = pre;
if (pre->rc == NULL)pre->rc = tree;
pre = tree;
}
}
void la(t** head, t* tree)
{
(*head)->l = 1;
(*head)->r = 0;
(*head)->rc = *head;
if (tree == NULL) (*head)->lc = *head;
else
{
(*head)->lc = tree;
pre = *head;
la1(tree);
pre->rc = *head;
(*head)->rc = pre;
}
}

然后是线索化后的无递归遍历，这里只粘贴了前序和中序，对于后序二叉树，我目前未看到可靠的无递归遍历算法。
前序，直接进入根节点，输出，在向左输出，直到左边没有子树，再向右走一步，再一直向左，重复，直到走回头节点。
void inorderh(t* head)
{
t* curr = head->lc;
while (curr != head)
{
printf(“%c “, curr->num);
if (curr->l == 1) curr = curr->lc;
else curr = curr->rc;
}
}
中序，则要先向左走到头，输出，然后看看右边是不是线索，以及是否到达尾节点，如果是线索，且不是尾节点，则进入线索指向的下一个节点，输出。
再重复判断，直到右边是子树或头节点，之后在向右走一步，循环直到回到头节点.
void inorderm(t* head)
{
t* curr;
curr = head->lc;
while (curr != head)
{
while (curr->l == 1) curr = curr->lc;
printf(“%c “, curr->num);
while (curr->r == 0 && curr->rc != head)
{
curr = curr->rc;
printf(“%c “, curr->num);
}
curr = curr->rc;
}
printf(“\n”);
}
