今天费了一番功夫把qqagent转移到了云服务器上，用的是阿里云的学生300代金卷，租了个2核2G的小服务器。
最开始用的是windows系统，因为我电脑用的就是windows系统，比较熟悉，但因为用的Server Core 无图形界，SnowLuma 起不来。
于是便转成liunx系统，有使得本机 ssh 工具全废，只能改用 Python + paramiko，后来又遇上zip 解压失败，Docker 装不上，OneBot 配置不生效等问题，逐一解决后终于完成了云端的部署，现在qqagent可以24h在线了，接下来准备继续完善桌宠和试试用AI控制手机。
